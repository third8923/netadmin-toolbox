【一、直接使用】

  双击  netadmin-toolbox.exe  即可打开图形界面。
  不需要安装，不需要 .NET / Python / VC 运行时，
  只有一个 exe，可以放在 U 盘里带走。

  建议右键 →「以管理员身份运行」，
  否则部分网络/系统功能（进程名、服务启动类型、端口占用）会读取不全。

  右上角「以管理员重启」按钮也可以自动提权。

  v2.14 界面：靛蓝主色的中性高级配色，四套主题随时切换（默认「晴空白」），
  Win11 沉浸式标题栏 + 圆角窗口，高分屏自动缩放。
  字号：正文 17px / 页标题 27px —— 还嫌小，就按 Ctrl + = 继续放大
  （85% ~ 180% 任意档，窗口会一起变大，选择自动记住）。
  结果表格整行自绘：39px 行高、细分隔线、首列加粗、数值右对齐，
  列表高度永远是整行，不会出现被切掉半行。
  结果和日志收在一张卡片里，各带段标题与右侧状态，数据少时日志自动占更多空间。
  右上角权限状态用胶囊显示，操作按钮带 Fluent 图标，
  对话框取消 / Esc / ✕ 三种方式随时关闭。
  日志面板为自绘控制台：拖动滚动条文字始终清晰，上翻看历史时
  新日志不会抢视角，回到底部自动恢复跟随。


【二、界面说明】

  左侧：两级可展开分组，共 69 个功能模块（点击组名收起/展开，记忆到下次启动）
        · 磁盘清理（5）  空间分析（6）  网络管理（10） 远程终端（3）
        · 网络诊断（3）  系统管理（5）  系统信息（5）  常用管理（6）
        · 软件管家（11） 安全体检（2）  净化中心（5）  密码工具（4）
        · 高级工具（2）  系统优化（1）  系统维护（1）
        顶部搜索框可实时过滤（Ctrl+F 也能激活，搜索时自动展开命中组）

  中间：结果列表（名称 / 数值 / 分类 / 详情，可双击看完整内容）
        · 点击表头「名称 / 数值」可排序，再点一次切换升降序
        · 红色行 = 高风险或「仅统计」项

  底部：实时日志
  底部状态栏：汇总（如「可清理 14 项 / 4.17 GB　仅统计 2 项 / 6.04 GB」）

  右上角「关于」按钮：版本信息 + 访问 biohacker.fun 官网。
  右上角「主题」按钮：四套界面主题卡片预览，点击即切换。

  四套主题（Ctrl+T 快速循环，选择自动保存，重启恢复）：
    · 晴空白（默认）冷调浅灰底 + 纯白卡面 + 靛蓝主色
    · 暖阳米      米纸暖底 + 陶土棕主色，护眼
    · 薄雾蓝      雾蓝冷底 + 钢蓝主色
    · 深空夜      石墨深空暗色 + 亮靛蓝主色，夜间低光
  当前主题名显示在左下角页脚右侧。


【三、快捷键与操作】

  Ctrl+F ....... 激活模块搜索框
  F5 ........... 重新执行当前模块扫描
  Esc .......... 停止正在运行的任务（在对话框里按则直接关闭对话框）
  Ctrl+T ....... 循环切换界面主题（晴空白→暖阳米→薄雾蓝→深空夜）
  Ctrl + = ..... 界面放大一档（字太小就按它，窗口一起变大）
  Ctrl + - ..... 界面缩小一档
  Ctrl + 0 ..... 缩放复位到 100%
  表头点击 ..... 排序（开关型「Windows 优化」锁定行序，防误排序）
  全选/取消全选  批量选中（Windows 优化模块）
  还原选中 ..... 对选中的优化项执行还原

  每次操作完成，右下角会弹出 Toast 轻提示（不打断操作）。

  对话框（确认框/关于）三种关闭方式：取消按钮、Esc 键、标题栏 ✕。


【四、常用功能怎么找】

  查 C 盘什么占地方 ....... 磁盘清理 → 基础清理 / 系统清理 → 开始扫描
  找大文件 ............... 空间分析 → 大文件查找（填路径 + 最小 MB）
  找重复文件/图片 ......... 空间分析 → 重复文件 / 相似图片
  第三方软件缓存 ......... 磁盘清理 → 应用缓存
  看本机配置 ............. 系统信息 → 系统概览 / 磁盘信息
  查端口被谁占用 ......... 网络管理 → 网络连接
  测网络通不通 ........... 网络诊断 → 网络诊断（目标填 8.8.8.8）
  扫局域网有哪些设备 ..... 网络诊断 → 局域网扫描（目标留空自动探测网段）
  换更快的 DNS ........... 网络管理 → DNS 优化（开始测速 → 自动优选）
  远程管理服务器 ......... 远程终端 → 远程会话（SSH/SFTP 一键连接）
  内网端口穿透 ........... 远程终端 → 端口转发隧道（-L/-R/-D）
  调试串口设备 ........... 远程终端 → 串口终端（COM 监视与收发）
  新机去广告/关遥测 ...... 系统优化 → Windows 优化（40 项，可还原）
  ghost 机封更新 ......... 净化中心 → 系统更新锁定（一键锁定，可还原）
  加入自建组网 ........... 网络管理 → 组网助手（粘贴配置串一键导入/扫码接入）
  修 hosts ............... 系统维护 → hosts 文件（编辑/添加映射/屏蔽模板，自动备份）


【五、命令行（适合批处理/远程运维）】

  netadmin-toolbox.exe --list                列出全部模块
  netadmin-toolbox.exe --help                帮助

  netadmin-toolbox.exe run sys.info
  netadmin-toolbox.exe run net.adapters
  netadmin-toolbox.exe run net.conn
  netadmin-toolbox.exe run clean.basic

  netadmin-toolbox.exe run net.diag     --target 8.8.8.8
  netadmin-toolbox.exe run net.portscan --target 192.168.1.1
  netadmin-toolbox.exe run scan.large   --path D:\ --target 500

  netadmin-toolbox.exe run sys.acct     --action 0 --target 新用户名
  netadmin-toolbox.exe run net.sharehost --action 9   （共享体检，只读）
  netadmin-toolbox.exe run net.sharemap              （扫描局域网共享，映射见 --help）

  netadmin-toolbox.exe run purg.wulock               （更新封锁状态扫描）

  netadmin-toolbox.exe run net.mesh                  （扫描 Tailscale 组网状态）
  netadmin-toolbox.exe run net.mesh --action 3       （终端输出接入二维码）
  netadmin-toolbox.exe run net.dnsopt                （公共 DNS 测速）
  netadmin-toolbox.exe run net.serial                （COM 口枚举）


【六、自己加功能（这是本项目的核心优势）】

  1. 在 src/modules/ 新建一个 .cpp
  2. 写个类继承 mz::IModule，实现 Id/Group/Title/Description/Kind/Run
  3. 文件末尾加一行：REGISTER_MODULE(你的类名);

  然后运行 build.bat。界面侧栏和命令行会自动出现这个新功能，
  ui/ 与 cli.cpp 一行都不用改。

  详细模板见 README.md 第 3.2 节。


【七、重新编译】

  需要 MinGW-w64 g++ 12 或更高版本。
  编辑 build.bat 里的 MINGW 变量，指向你的 mingw64\bin 目录。

  build.bat          增量构建
  build.bat clean    清理后全量构建

  产物：dist\netadmin-toolbox.exe


【八、安全提示】

  · 清理功能会真实删除文件，不可恢复，请先看清列表再执行
  · pagefile.sys / hiberfil.sys / WinSxS / Windows.old 只统计不删除，
    需按提示用系统工具（DISM / cleanmgr / powercfg）处理
  · 软件搬家建议先拿无关紧要的小目录试一次
  · 局域网/端口扫描请只对自己有授权的网络使用
