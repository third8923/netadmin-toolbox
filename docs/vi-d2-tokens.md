# biohacker.fun VI · D2「蜕变之翼」设计 Token 规范（UI 重构输入）

> 来源：vi-manual-D2.pdf（品牌识别手册 V1.1，2026-10-29，方向 D2 已选定）。
> 本文档把手册提炼为 NetAdmin Toolbox UI 重构可直接引用的 token 与纪律。
> 铁律：变量即规范——代码里引用 token 名，不写死色值。

## 0. 设计立场（先读这个）

- 明亮、好奇、爱折腾、有幽默感——科技感从生命形态里长出来
- **明确拒绝**：终端绿+黑底的默认黑客皮、SaaS 蓝、企业公司的「可信赖」脸
- **明确拒绝**：渐变、外发光、硬投影、skew/透视、第三档线宽
- 金色只做信号指向（全版面 ≤10% 面积）；铺面/渐变/描边 = 降级为装饰 = 犯规
- 走线是信号不是墙纸：没有信号流过的地方，宁可留白也不排线

## 2. 字体系统

| 层 | 字族 | 字重 | 用途 |
|---|---|---|---|
| Display | **Baloo 2**（OFL 开源） | 800 | 字标、封面、页题；圆头粗体；display 负字距 -0.01em |
| Body | Noto Sans SC（系统落地方案：Microsoft YaHei UI） | 400 / 700 | 正文 15–16px，行高 1.85；强调用 700 不用斜体 |
| Data | **JetBrains Mono**（OFL 开源；系统落地：Cascadia Mono → Consolas 回落） | 400 / 600 | 数据层专用：IP、端口、色值、参数、页码；tabular-nums |

| 层级 | px | 字重 | 用途 |

| 字标 | 88 | 800 | 仅封面/关于页 |
| 页题 | 40 | 800–900 | 大标题 |
| 标题 | 22 | 700 | 面板与卡片标题 |

## 3. 图形语言（电路板四元语法）

- **走线 TRACE**：只走 45° 折线，不兜圈子；线宽两档——走线 3.5u、标注引线 1.5u，无第三档
- **焊盘 PAD**：只在走线末端；圆环外径 12u
- **过孔 VIA**：实心点 r 2.8u，只标蜕变点/版本跳变点
- **丝印 SILK**：等宽小字标注（U1 式）
- 空状态 = 线稿走线，「信号没到，线就不画完」；错误与空状态**不上 err 红**（err 只归数据层）
- 圆角两档：卡片 12px / 胶囊 999px；12 栏网格、栏距 24px
- 蜕变四态叙事：卵 v0.1 → 幼虫 v0.5 → 蛹 v0.9 → 蝶 v1.0（版本页/启动画面可用）

## 4. 标志（主标志构造参数，GDI 可直译）

画布 240×160（12×8 网格，单元 20u）；蝶形外切 192×104 居中：
- 上翅：藤紫 192×62（两片），内含走线焊盘——两段 45° 折线通向 2 枚金焊盘（圆环外径 12u）
- 下翅：金 96×44 实心基板（两片）
- 蝶身+触角：墨，身宽 12u；触角 22u、仰角 45°
- 过孔：实心点 r 2.8u，翅根两枚
- 净空间：外切矩形高度的 1/2
- 字标：biohacker 与 fun 之间的**金点=焊盘**，位置大小固定，不可拆分移位
- 版本：A 完整组合 / B 单色墨 / C 反白（墨底：蝶身纸色、上翅 #B293FC、焊盘保持金）/ D 字标 / E 蝶形符号（24×24 方瓣圆头，favicon/图标用，最小 16px）

## 5. 禁忌清单（违反 = 打回）

1. 蝶翅只认 #FBF7EC 这张纸（不换米黄/牛皮纸底）
2. 金 ≤10%，不铺面、不渐变、不做大面积描边
3. 走线不当背景纹样
4. 不拉伸/旋转/特效：禁 skew、透视、外发光、渐变填充、硬投影
5. 不换字体不加尖角：字标只用 Baloo 2 800；圆头语言，无尖角框
6. 藤紫原色禁止直接上墨底（必须 #B293FC）；纸色字禁止上金面（墨字才行）
7. 数据通道色不做按钮/标题
