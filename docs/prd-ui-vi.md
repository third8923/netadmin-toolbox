## 1. 项目信息

- **Language**：中文
- **Programming Language**：C++20 + MinGW-w64，纯 Win32 owner-draw（GDI/GDI+ 双缓冲），维持零第三方库
- **Project Name**：netadmin_toolbox_v217_vi_d2_refactor
- **原始需求复述**：用户要求「参考 VI 文件（biohacker.fun 品牌识别手册 D2），对整个软件的 UI 进行重构，要做出世界一流大师的水准」。即：把现有靛蓝主题体系（clear-day / warm-sand / mist-blue / deep-night 四主题）整体替换为 VI-D2 设计体系（纸 #FBF7EC / 墨 #3A3A44 / 藤紫 #7C5CBF / 金 #F2B441 + 数据通道色），覆盖 69 模块 / 15 分组的全部界面，同时不破坏单文件免安装、dpi 缩放、三语（简/繁/英）与任何既有功能。

## 2. 产品定义

### 2.1 Product Goals

1. **品牌级视觉重构**：全软件 UI（标题栏、侧栏、主区、表格、对话框、日志、按钮、空/错误状态）从靛蓝 Fluent 风格整体迁移到 VI-D2 设计体系，视觉水准达到品牌手册级——「变量即规范」：代码只引用 token 名，不写死色值。
2. **双主题 + 数据可读性**：落地纸亮（paper 底）与墨暗（ink 底）两套合规主题，暗色严格遵循「墨底 + 纸字 + 金信号 + 藤紫提亮变体」推导；数据密集界面（结果表格、日志）引入数据通道色与等宽字体层，专业可读。
3. **零回退约束下的重构**：重构全程保持零第三方 UI 库、单文件 ~3.5MB 量级、dpi::S() 缩放 85%–180%、三语切换、69 模块功能与交互行为零回退；金 ≤10% 面积、正文对比度 ≥4.5:1 成为验收硬指标。

### 2.2 User Stories

1. **As a** 网管工程师，**I want** 首次启动就看到「纸底 + 墨字 + 藤紫蝶翅 + 金信号」的品牌化主界面，**so that** 一眼认出这是 biohacker.fun 家族工具，产生专业且独特的第一印象（视觉冲击 ≠ 换壁纸，而是色彩纪律 + 字体层级 + 蝶形标志的整体气质）。
2. **As a** 深夜值守的管理员，**I want** 按 Ctrl+T 在「纸亮 / 墨暗」两套主题间一键切换且切换后所有 owner-draw 控件（含对话框、日志、状态徽标）即时正确重绘，**so that** 任何光线环境下都舒适且不降低对比度合规性。
3. **As a** 排查 300+ 条 TCP 连接的运维，**I want** 结果表格中的 IP/端口/参数使用等宽 JetBrains Mono 数据层字体、时间戳右对齐 tabular-nums、成功/产出/异常行用通道色语义着色，**so that** 密集数据可逐行扫读、异常行 1 秒定位。
4. **As a** 首次使用某模块的新手，**I want** 空状态看到「线稿走线 + 未画完的电路 + 一句引导文案」的品牌化空态，而不是空白表格，**so that** 我知道「信号还没到」该先点哪里，且体验有品牌记忆点。
5. **As a** 遇到扫描失败的用户，**I want** 错误状态以走线断点/标注引线 + ink55 说明文字呈现（不上刺眼红色横幅），**so that** 我冷静地知道哪一步没通、下一步怎么办，而不是被吓到。
6. **As a** 关注这个开源项目的用户，**I want** 在「关于」页看到蝶形标志 + Baloo 2 字标（金点=焊盘不可拆分）+ 蜕变四态叙事（卵 v0.1 → 幼虫 v0.5 → 蛹 v0.9 → 蝶 v1.0）与版本历史，**so that** 我理解产品的成长故事并愿意收藏/传播。
7. **As a** 高分屏笔记本用户，**I want** 85%–180% 缩放、三语切换下侧栏分组层级、字号层级（七级字阶）与圆角规格（卡片 12px / 胶囊 999px）严格保持，**so that** 任何设置组合下界面都精致不破相。
8. **As a** 熟练用户，**I want** 重构后的侧栏用 panel 系底色与选中态藤紫明确区分「分组 / 模块 / 当前项」三层级，且 Ctrl+F 搜索、F5、Esc 等快捷键行为不变，**so that** 肌肉记忆零成本迁移。

## 5. 约束与风险

1. **纯 Win32 owner-draw**：GDI/GDI+ 双缓冲已具备（`src/ui/gdi.*`），不得引入任何第三方 UI 库、图像解码库或字体渲染库；所有品牌图形（蝶形、走线、焊盘、过孔、四态叙事）必须 GDI 矢量直译构造参数，禁止预渲染位图资源（图标资源除外）。
2. **字体方案（由架构师最终定）**：Baloo 2 与 JetBrains Mono 均为 OFL 开源，可内嵌子集经 `AddFontMemResourceEx` 内存加载；正文回落系统 Microsoft YaHei UI，Data 层回落 Cascadia Mono → Consolas。风险：内嵌子集增大单文件体积（预估 +100–300KB，需控制在可接受量级）；子集字符集需覆盖三语标题用字。
3. **金 ≤10% 面积纪律**：金只做信号指向（进度、焊盘、金点、信号小字），铺面/渐变/大面积描边 = 犯规；每屏评审时以金像素占比抽查。
4. **对比度规格**：正文 ≥4.5:1 为硬验收线，手册实测值直接引用（见 P0-2）；暗主题派生色未达标不得合入。
5. **dpi::S() 缩放不破坏**：所有新 token 尺寸（12px 圆角、24px 栏距、线宽两档、网格单元 20u、过孔 r2.8u 等）必须经 dpi 缩放管线；85%–180% 全程无破相。
6. **禁忌清单（违反 = 打回）**：蝶翅只认纸底；金不铺面不渐变；走线不当背景纹样；禁 skew/透视/外发光/硬投影；字标只用 Baloo 2 800、无尖角框；藤紫原色不上墨底、纸色字不上金面；数据通道色不做按钮/标题。
7. **零回退风险**：69 模块 + CLI + 三语 + 缩放 + 危险确认全量回归；重构以 token 层 + 控件绘制层为改造边界，模块层（`src/modules/`）与插件框架零改动。
8. **杀软启发式**：新增内嵌字体资源需验证不触发杀软误报（现状已有 base64 规避经验可复用）。
